# internet-speed-test

Консольный скрипт на Python для замера скорости скачивания. Принимает URL (например, тяжёлую картинку), делает к нему несколько последовательных HTTP-запросов, дожидается полного тела каждого ответа и считает среднее время запроса, общий объём скачанных данных и скорость загрузки.

## Требования

- Python 3.8 или новее
- Только стандартная библиотека (`urllib`). Дополнительные пакеты не нужны.

## Как запустить

```bash
python3 speed_test.py https://upload.wikimedia.org/wikipedia/commons/3/3f/Fronalpstock_big.jpg
```

Параметры:

| Параметр | Описание |
| --- | --- |
| `url` | Адрес, к которому стучаться |
| `-n`, `--count` | Число последовательных запросов (по умолчанию 10) |
| `--timeout` | Таймаут одного запроса в секундах (по умолчанию 60) |

Другие примеры:

```bash
python3 speed_test.py -n 5 --timeout 30 https://upload.wikimedia.org/wikipedia/commons/3/3f/Fronalpstock_big.jpg
python3 speed_test.py --help
```

При ошибке HTTP, сети или таймауте скрипт печатает сообщение в stderr и завершается с кодом 1. При некорректных аргументах код выхода — 2.

## Единицы измерения

- 1 МБ = 10^6 байт
- 1 Мбит = 10^6 бит
- Скорость выводится в Мбит/с и в МБ/с

Это десятичные единицы, принятые в сетях, а не двоичные мебибайты (1 МиБ = 2^20 байт).

## Как считается скорость

- Среднее время запроса — сумма времён всех успешных запросов, делённая на их число.
- Общий объём — сумма размеров тел ответов в байтах.
- Скорость в МБ/с: `общий_объём / 10^6 / суммарное_время`.
- Скорость в Мбит/с: `общий_объём × 8 / 10^6 / суммарное_время`.

В время каждого запроса входит установка соединения, получение заголовков и полное чтение тела ответа. Запросы выполняются строго последовательно: следующий стартует только после завершения предыдущего.
